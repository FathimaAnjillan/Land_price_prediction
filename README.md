# Land_price_prediction
Machine learning model that predicts land prices from property features, built in Python
Private (provided by the bootcamp), so not uploaded here.

## Problem
Estimate the price of a piece of land from its features.

## Dataset
Private, so not uploaded here.
16 columns- id, location, taluk, village, latitude, longitude, land_area, land_type, distance to airport, distance to railway station, distance to hospital, distance to medical college, distance to bus station, distance to market, price

## Approach
1. Data cleaning (handling missing values, duplicates)
2. Exploratory data analysis
3. Feature selection / encoding
4. Model training  Random Forest

## Results
Predict a new data

## Tools Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Google Colab

## How to Run
1. Consider the required dataset
2. Install the requirements
3. Open `land_price_prediction.ipynb` and read the dataset, run all cells
